PlxNative is an independent client for Plex Media Server, built to make browsing feel fast, smooth, and enjoyable again on LG webOS TVs — even older ones.

Open source · No root required · Built for LG webOS

Why I built PlxNative

My TV still had a great panel. But using the official Plex app on it had become frustratingly slow.

The TV itself was still perfectly good — replacing it, or adding another box just to get a responsive interface, felt like the wrong solution. So I built the client I wanted to use myself.

See how it feels

Responsiveness is hard to describe. It is easier to show.

Fast doesn't have to mean stripped down.

Performance was the reason PlxNative started. It was never the whole goal.

Built differently

PlxNative draws its interface directly on your TV instead of running it inside a web browser. That keeps it lightweight: the app opens in about a second, with smooth scrolling and responsive menus.

  • OpenGL

Before you install

Compatibility notes · Privacy policy

LG webOS

Built for webOS 4.0 and newer. Compatibility can vary by TV model.

Plex

Requires a Plex account and Plex Media Server.

Playback

PlxNative uses the codecs available on your television and falls back to Plex transcoding when needed.

Privacy

Crash reporting and usage analytics are optional and disabled by default.

PlxNative is an independent, unofficial client for Plex Media Server. It is not affiliated with or endorsed by Plex GmbH or LG Electronics.
