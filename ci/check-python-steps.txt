# The Python / shell / C gates of `make check-python-rest` (and so of `make check`, and of CI's
# "host python/shell/C gates" job): ONE COMMAND PER LINE, run by `tools/check-parallel.py --steps`.
#
# This file is the single list. The Makefile's `check-python-rest` is only the runner over it and CI
# runs that target, so a line added here runs in `make check` and in CI with no second place to edit;
# `ci/test_ci_split.py` fails if a test file exists that no gate names (add it here, or to the
# exemption list there with a reason) and if the target stops being exactly that runner.
#
# FORMAT. A line is a command split like a shell word list: no pipes, no `&&`, no redirects. Blank
# lines and `#` lines are ignored. A line may appear once. A step passes when it exits 0.
#
# THE STEPS RUN CONCURRENTLY (a bounded number at once, `--jobs auto`; every step runs even when one
# fails, and each step's whole output is printed when it ends). So a step in this file must:
#   * write only to a directory it made itself (`mktemp -d`, `tempfile`), never to a fixed path in
#     /tmp or $TMPDIR, the checkout, `$HOME` or `~/.cache`; and a fixture that edits "the repo" edits
#     a private copy of it;
#   * bind port 0 (an ephemeral port), never a fixed one;
#   * not take `tools/check-lock.py`'s real lock (ci/test_check_lock.py uses a throwaway path), not
#     run cargo, and not assume it is the only `make` running;
#   * not read a file another step writes.
# `ci/test_check_collisions.py` runs these steps side by side to check the first rule; a step that
# breaks one of them shows up there rather than as a flake in somebody else's `make check`.
#
# ORDER is only the START order: the sixteen slowest steps (measured 2026-10-07) come first, so the
# last one to start is a short one; the run lasts as long as the longest step plus the queue. A new
# step goes at the END; move it up only after measuring (`make check-python-rest` prints each step's
# wall and CPU time and the slowest three).
