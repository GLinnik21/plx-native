## Approved source corrections

**DIFF-05 — constructor readiness is within the issued budget.** The source pump returned early
when `sf_ready == 0`, before reaching its 20-second wait. A synthetic not-ready object plus a
backdated issued timestamp reproduced RED at “constructor readiness must not bypass the issued
budget.” Applying the shared in-flight gate to that early return makes it GREEN. An unexpired
not-ready object remains Connecting. Ready-object demux failures retain their earlier precedence;
a RED→GREEN ordering regression covers this. The return-to-loadCompleted budget stays independent.

**DIFF-06 — stale Load failure cannot poison the next epoch.** The source Load worker wrote the
shared failure flag even after its native epoch was retired. A refused old epoch followed by a
new active epoch reproduced RED at “a stale worker must not poison the newer epoch.” The write
now holds Shared's native-session retirement/reset lock and checks the active epoch. The stale
case is GREEN; a current synchronous refusal still publishes failure. Route-result publication
retains its existing separate ticket correlation. Both corrections require independent review.

and service/command/timeout distinctions. Replay requests are removed before resource dispatch;

and disclosure. Its destination `frames`/`set_choice` API remains; source `move_focus`/`press_at`
were not restored. Consent changes only pass the question at open time. The player screen shape
