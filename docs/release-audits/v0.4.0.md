## Compatibility tiers, and what moved

Nothing moved. The four tiers are v0.3.0's, unchanged: verified on 2019 sets, reported on one 2021 set, starting on every firmware from webOS 4.0 up, not starting below that.

**This release reaches further over the network than any before it, and that is not a compatibility change.** v0.3.0 and earlier only ever dialled an address on the local network; this one will reach a server over the internet, because that is how a share is normally reached. It changes which servers work, not which televisions do.

## Known issues at release, with provenance

- **Plex Relay, servers requiring secure connections, and servers reached by hostname or IPv6.** The app speaks plain HTTP to a numeric address and has no name resolver, so none can be dialled at all. Structural.
- **10-bit decoding is still asserted rather than probed** — the codec table has no column for it.
- **Whether a television enters its Dolby Vision mode on this declaration is unconfirmed.** The declaration is made and the pipeline accepts it; no panel has been watched. Profile 7's enhancement layer cannot be fed by this pipeline and is refused.
- **On webOS 5 and newer, seeking reloads the stream** rather than moving within it.

## The safety trigger fired twice, and both are disclosures above the features

**A PIN on a Plex Home profile could be skipped at the boot picker.** BACK entered the app as whoever was signed in last. Nothing left the television and no credential was exposed off it; what was wrong is who the app let in at its own front door. v0.1.0 through v0.3.0 are affected. Placed above the features because a reader with a protected profile needs to know before they read about Search — even though the action is only "install this release" — and cross-referenced from `Fixed` so a changelog reader is routed rather than told twice.

**This release is the first that will reach a server over the internet, in plain text, with the access token in the address.** No earlier release is affected and nothing has leaked; it is disclosed because the reach is new and the reader is the only person who can decide whether they are comfortable with it. There is no setting for it, which the note says.

## Deliberately not done

**A blur behind the scrolling band was built, measured on the television and thrown away** — it cost more than it was worth. `docs/backdrop-blur-profiling.md` records what it cost and the instrument that priced it.
