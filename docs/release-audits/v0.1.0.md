# Release audit — v0.1.0

The evidence behind [the v0.1.0 release note](https://github.com/tiper/fin-native/blob/main/docs/release-notes/v0.1.0.md). Written for a webosbrew reviewer, a contributor auditing an old release, and us in a year. The section at the bottom is generated from the artifact that was published; everything above it was written by a person before the release ran.

This is FinNative's first release. Its version numbers are its own: PlxNative's releases with the same numbers are a different application (`com.beb.plxnative`).

## Device test evidence

| | |
|---|---|
| television | LG C1, platform release 6.5.3 (LG markets this generation as webOS 6) |
| server | Jellyfin on the developer's own network |
| suite | not run: `./tests/run.py` drives a Plex server and the FinNative backend has no suite of its own yet |
| by hand | debug builds of this tree (`io.github.tiper.finnative.debug`) installed with webOS Dev Manager throughout development: sign-in, Home, libraries, search, and films and episodes played directly and transcoded by the server |

Only one television and one server have run FinNative. Nothing in this release was measured for frame rate on the set.

## External compatibility reports known at release time

None. FinNative has not been run by anyone else on any television.

## Compatibility tiers, and what moved

First release, so nothing moved. The LG C1 is the only set that plays video by observation. Every other tier is the static loader check in the generated block below, which grades whether the process starts and cannot see a video plane.

## Known issues at release, with provenance

None recorded for this package.

## Deliberately not done

- No crash reports and no usage analytics: the build compiles in no Sentry DSN and no PostHog key (`telemetry: none` in the release workflow), so nothing is uploaded to Sentry either.
- No nightly channel and no project website: PlxNative's `nightly.yml` and `pages.yml` are disabled in FinNative's repository.

## Release configuration

| | |
|---|---|
| flavour | `io.github.tiper.finnative` (stable), the id users install; `FLAVOR: stable` is pinned in the release workflow's build job |
| cargo features | `RELEASE=1`, which drops `devtools` and `devtriggers` |
| telemetry | none: no endpoint is compiled in and the build step asserts the binary carries none |
| built on | PlxNative 0.9.0 and the upstream changes to [f0e9b85b](https://github.com/GLinnik21/plx-native/commit/f0e9b85b) (2 November 2026); About prints `PlxNative 0.10.0-dev` (`PLXNATIVE_BASE`) |
| built by | GitHub Actions, from the tag, at a path identical on every runner |
| toolchain | webOS NDK and the stable Rust release pinned in `rust-modules/rust-toolchain.toml`, as inherited from PlxNative |

Nothing else is unusual about this build.
