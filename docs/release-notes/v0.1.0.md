# v0.1.0 — FinNative's first release

FinNative is a native Jellyfin client for LG televisions, built on PlxNative's player, interface and webOS port. This is its first release: it signs in to your own Jellyfin server and plays your films and shows with the television's own decoders.

It is built on PlxNative 0.9.0 and the PlxNative changes after it, up to 27 October 2026 ([0f297965](https://github.com/GLinnik21/plx-native/commit/0f297965)). Settings > About names that base on every build.

## What's new

- **Sign in to a Jellyfin server.** With Quick Connect from a phone, or with the server's address, a username and a password. Servers on your network are found for you.
- **Your libraries, as your server shows them.** Home follows your Jellyfin home screen settings, and libraries, collections, seasons, episodes and the people in them each have a page. Search finds films, shows and people, and a library can be filtered by genre.
- **Playback the server agrees with.** Before a video starts, FinNative tells your server what this television can decode, and the server decides whether it plays the file directly or converts it, within the limits its administrator set. Audio the television cannot decode is converted by the server, or by the television itself if you choose it in Settings > Playback > Convert audio.
- **The parts of watching you expect.** Resume where you stopped, the next episode, Skip Intro and Skip Credits where the server knows them, scrub thumbnails, your audio and subtitle preferences, subtitle search through the server, and favourites.

## Compatibility

- **Plays video, verified by watching it — 2021 LG sets.** One television: an LG C1, which reports platform release 6.5.3. FinNative was developed on it; the audit says what was run on it.
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up is expected to start.** This binary's libraries and symbols are checked against the firmware images webosbrew has; the result for this build is in the [technical audit](https://github.com/tiper/fin-native/blob/main/docs/release-audits/v0.1.0.md). That grades startup and says nothing about whether video plays.
- **Does not start — webOS 3.9.2 and older.** Symbols the app needs are missing there, so the process is killed before anything appears.

If your set is in the middle group, [tell us what happened](https://github.com/tiper/fin-native/issues). It working is as useful a report as it failing.

## Help test this release

**If you have a television other than an LG C1**, install it, play a film and an episode, and tell us what you saw. Nobody has run FinNative on any other set.

## Installing

Download **io.github.tiper.finnative_0.1.0_arm.ipk** and install it with [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). FinNative is not in the Homebrew Channel yet. You do **not** need a rooted TV. FinNative installs beside PlxNative; it is not affiliated with Jellyfin or PlxNative.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  io.github.tiper.finnative_0.1.0_arm.ipk
```

[Installing and checking a download](https://github.com/tiper/fin-native/blob/main/docs/install-finnative.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. This package bundles FFmpeg under LGPL-2.1-or-later and its complete corresponding source is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.1.0](https://github.com/tiper/fin-native/blob/main/docs/release-audits/v0.1.0.md).
