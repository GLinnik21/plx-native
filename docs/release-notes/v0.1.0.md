---

The first public release: a native Plex client for LG webOS, drawn with OpenGL ES 2 and playing
video through the television's own hardware decoder rather than a browser.

## Which televisions this works on

| Firmware | State |
|---|---|
| webOS 4.4.2 – 4.10 | The app runs and playback works. Verified on one television (webOS 4.10). |
| webOS 5.0 and newer | **Does not start.** The process is killed by the dynamic loader before `main`. |

This release declares `webosRelease: '>=4.0, <5.0'` for that reason: it links directly against
`libAcbAPI` and against FFmpeg SONAMEs that only exist on webOS 4.x, and a `DT_NEEDED` entry is a
hard requirement for one exact name.

## What it does

Sign in on the television with an on-screen QR code, pick a Plex Home profile, browse your library
and play. Direct play where the TV can decode it; the server is asked to transcode only when it
genuinely cannot. Resume, seek, chapters, audio and subtitle track switching, and progress reported
back to your server.

## Installing

Install the `.ipk` with the [Homebrew
Channel](https://github.com/webosbrew/webos-homebrew-channel) or
[dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). No rooted TV is needed —
the app runs in LG's ordinary sandbox as an unprivileged user.

## Checking what you downloaded

Nothing anywhere in this distribution chain is signed — there is no code signing in the webosbrew
path at all — so this sha256 is what tells you the file you have is the file that was published
here.

```
fc0a67de5ff6e209f1ca36add1b34cb689fa71d50a5e47dfac3631c788995105  com.beb.plxnative_0.1.0_arm.ipk
```

Check it with `shasum -a 256 com.beb.plxnative_0.1.0_arm.ipk` on macOS or Linux, or
`certutil -hashfile com.beb.plxnative_0.1.0_arm.ipk SHA256` on Windows. The `ipk.sha256` asset
cannot be used with `-c` for this release — see the update at the top.

If the Homebrew Channel installs this for you from its catalogue, it fetches this release's
`com.beb.plxnative.manifest.json`, hashes the download on the television and refuses to install a
package that does not match — you have nothing to do. Pointing the Channel at a bare `.ipk`
yourself skips that check, so check it yourself.

Built by GitHub Actions from commit `a68a632`. The assets attached here are that run's artifacts,
unmodified — nothing was rebuilt or re-uploaded by hand.

## FFmpeg

This release bundles no FFmpeg. It reads media through the television's own libraries, resolved at
runtime — which is why behaviour differed between firmware versions, and why v0.2.0 bundles its
own instead. No LGPL redistribution obligation arises from this package.

## Still the same scope

Movies and TV shows, from a Plex Media Server on your local network. No music, photos, live TV or
DVR, and no way to enter a remote server address.

## Known not to work

- webOS 5.0 and newer: the app does not start at all.
- Codec capability is asserted rather than probed — the app tells your server it can handle HEVC,
  4K and 10-bit because the author's television can.
