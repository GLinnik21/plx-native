# v0.7.0 — a rebuilt interface, a library that reads as one page, and your local server with no internet

This is the first new minor release since 0.6.0. Every screen now runs on one shared interface framework, the Library is one scrolling page with your favourite libraries at its head, trailers play from movie and show pages, and a server on your own network keeps working when the internet is down. Every fix shipped in 0.6.1 through 0.6.6 is included.

## When updating from 0.6: install over your existing app

Install v0.7.0 over the PlxNative you already have. Do not uninstall it or choose **Delete all local data** first: on its first start, 0.7.0 takes over the sign-in, profiles, Home choices and reporting answers that 0.6.0 through 0.6.6 stored, and you should not be asked to sign in or to answer the reporting question again.

This is a forward migration only. Going back to a 0.6 release afterwards, uninstalling and reinstalling, or clearing local data is not guaranteed to keep your sign-in.

## If you share this television: it now keeps what it needs to switch profiles offline

So that the who's-watching picker still works when the internet is down, 0.7.0 keeps, for every profile that has been used on this television, that profile's access to your servers and — for a PIN-protected profile — a one-way check derived from its PIN. The PIN itself is never stored. Earlier versions kept only the profile in use.

**What to do:** nothing, if you are happy for that to be kept on the television. **Sign out** in Settings, or **Delete all local data**, removes all of it, together with your sign-in.

**What is fixed, and what is not:** a PIN-protected profile still asks for its PIN offline, exactly as it does online. A PIN has few enough possible values that someone able to read the app's private storage on the television could recover it from that check by trying them all. A profile PIN protects against whoever is holding the remote, not against someone with that kind of access to the set.

## What's new

- **Watch your own server when the internet is down.** A server on your home network is reached directly even when plex.tv and Plex's public addresses are unreachable, and the profile picker, profile pictures and a PIN-protected profile's PIN all work from what the television already has. Signing in for the first time still needs the internet.
- **The Library is one page.** Each library's own shelves come first and the full A–Z grid follows on the same scroll, with every control inside it. Choose favourite libraries in Settings, and they become the tabs at the top, the libraries the Library offers, and what Search ranks first — Search still finds everything you have access to. A Plays sort is offered wherever your server supports it.
- **Trailers.** Movie and show pages with a trailer on your server offer it, both from the page and from the item menu. Press UP on a trailer playing behind the page to watch it full screen, with its own play, pause and seek; watching a trailer never marks anything watched.
- **A person's full filmography.** A person page opens every credit Plex knows for them, by department, and marks the ones you can play.
- **Automatically Sign In.** A new switch in Settings → System skips the who's-watching picker at startup and opens the profile you last used. It is off unless you turn it on. Turned on while a PIN-protected profile is in use, the next start opens that profile **without** asking for its PIN — that is the point of the switch, so leave it off if the PIN matters.
- **Audio and subtitle languages follow Plex.** A show's own audio and subtitle language settings are honoured, and otherwise the audio language set on your Plex account; when nothing is set, the file's own default track is chosen rather than an English one. External subtitle files next to a video now show up when it plays directly.
- **One interface framework under every screen.** Home, Library, Search, the item pages, Settings, sign-in and the player were rebuilt on one set of shared controls. Most of this is meant to be invisible; what you may notice is that menus and dialogs keep the page underneath them in view, moving to a new page keeps its artwork on screen instead of flashing grey placeholders, and focus starts at the top of a page you have just opened.

## Fixed

- **A garbled picture on some Dolby Vision files, on televisions without Dolby Vision.** The app told every television that it was sending Dolby Vision; it now asks the television whether it supports Dolby Vision first, and plays the standard picture where it does not.
- **A picture that froze for more than a minute when a connection collapsed** during Auto quality. Every network wait during playback now has a limit, so a collapsing connection no longer holds the picture still while one request waits it out.
- **Posters that stayed grey.** A poster whose download failed once is tried again, artwork dropped from memory is fetched again when you come back to it, and a fast scroll through a large library no longer stutters while it fetches art it will not show.
- **Servers that could not be reached.** A server published with a custom access address is dialled on the port it gives; an address the app could not safely send your credentials over is no longer chosen when a working one exists; and a remembered server is only used again if it can be reached safely.
- **Playing in Original quality on newer Plex Media Server versions**, which can refuse to hand over the file unless the app has first told the server what it is about to play. The app now always does.
- **Staying signed in when the television's storage service is unavailable.** You can sign in and get into the app even if nothing can be saved, a sign-in kept in the backup file is used on the next start, and the interface no longer slows to a crawl while that service is unresponsive.
- **Smaller fixes you may have run into:** a seek no longer throws the playback bar to the left edge or flashes the old position; player menus are no longer hidden behind Stats for nerds; every player control you can reach with the arrow keys now also answers the Magic Remote pointer; the focused chapter is marked clearly over the video; Home shows the Recently Added row of every library, not only the first of each kind; pressing UP into the season list lands on the season you are looking at; the episode spinner no longer stays up after choosing a season; a profile list the account cannot load says so and BACK leaves it; and a profile that sees only one library no longer gets a library selector with nothing to select.
- **Everything fixed in 0.6.1 through 0.6.6** — the playback crash at the start of any video on some 2019 sets and the Repair button for their video sandbox, the sign-in that did not stay on 2024 and newer sets, the storage details and reports on the sign-in screen, IPv6 addresses in event logs, and a backgrounded app that kept drawing. See the notes for [0.6.1](https://github.com/GLinnik21/plx-native/releases/tag/v0.6.1), [0.6.2](https://github.com/GLinnik21/plx-native/releases/tag/v0.6.2), [0.6.3](https://github.com/GLinnik21/plx-native/releases/tag/v0.6.3), [0.6.4](https://github.com/GLinnik21/plx-native/releases/tag/v0.6.4), [0.6.5](https://github.com/GLinnik21/plx-native/releases/tag/v0.6.5) and [0.6.6](https://github.com/GLinnik21/plx-native/releases/tag/v0.6.6).

## Changed

- **PlxNative's own code is now licensed GPL-3.0-or-later**, replacing MIT. The permission earlier versions were released under is not withdrawn. The complete corresponding source of this release is attached to it.
- **Nobody is asked the reporting question again by this update.** If a sign-in fails, the app can offer to send one report about it; it sends nothing unless you agree, each time, even if you already turned error reports on. Crash reports that follow a program error now carry that error itself, and a crash is kept for the next start instead of being lost when the report could not be read. The full list of what a report can carry is in [the privacy policy](https://github.com/GLinnik21/plx-native/blob/main/PRIVACY.md).
- **A Developer Mode shell can now read a short storage diagnostics file** beside the app's logs, so a sign-in problem can be reported without root. It carries no token, no account name and no server address.

## Compatibility

- **Plays video, verified by watching it — 2019 LG sets.** One television: an LG 49SM9000PLA, which reports platform release 4.10.2 (LG markets this generation as webOS 4.5). PENDING — device pass not yet run.
- **Plays video, reported by someone else — one 2019 set and one 2021 set.** [Robert](https://github.com/RobertSmits) got playback back on a 2019 set built on LG's k5lp chip after repairing its video sandbox, running v0.6.3, on 2026-09-11: [issue #74](https://github.com/GLinnik21/plx-native/issues/74). [mariotaku](https://github.com/mariotaku) of webosbrew ran v0.2.1 on an LG 65UP7560AUD (platform release 6.5.2) on 2026-08-11 and got a picture: [issue #22](https://github.com/GLinnik21/plx-native/issues/22). Neither report has been repeated on this version.
- **Starts, and nothing further is known — every other firmware from webOS 4.0 up.** The loader resolves this binary's libraries and symbols against every firmware image webosbrew has at 4.0 or newer. That grades startup and says nothing about whether video plays; the matrix is in the [technical audit](https://github.com/GLinnik21/plx-native/blob/main/docs/release-audits/v0.7.0.md). PENDING — confirm against this release's generated matrix.
- **Does not start — webOS 3.9.2 and older.** Symbols the app needs are missing there, so the process is killed before anything appears.

If your set is in the middle two groups, [tell us what happened](https://github.com/GLinnik21/plx-native/issues). It working is as useful a report as it failing.

## Known issues

- **A crash on televisions built on LG's k6hp chip**, seen only in opt-in crash reports and not reproduced here, because no such set is available: [issue #174](https://github.com/GLinnik21/plx-native/issues/174). This release does not fix it; its crash reports should now carry enough to locate it.
- **Styled ASS subtitles, common on anime, show as plain text** when a video plays directly: [issue #73](https://github.com/GLinnik21/plx-native/issues/73). Choosing a lower quality in the player's menu makes the server draw them into the picture, styling included.
- **Auto has only been exercised in a laboratory** — one television, one server, and a link throttled on purpose.
- **Playback on webOS 5, 7, 8, 9, 10 and 11 is unverified.** The app starts there and nobody has reported watching anything on this version.
- **Servers behind Plex's relay, and servers that require an encrypted connection**, are reached but have not been watched end to end.

## Help test this release

**If you are updating from any 0.6 release**, install over it and tell us whether you were still signed in, on the same profile, without being asked the reporting question again. **If your television is a 2024 LG set or newer**, try a video that needs a server transcode: an earlier fix for sets that refused every transcode has still not been re-checked on that hardware. **If your set has no Dolby Vision** and a Dolby Vision file used to look garbled, try it again. [Open an issue](https://github.com/GLinnik21/plx-native/issues). It working is as useful a report as it failing.

## Installing

Download **com.beb.plxnative_0.7.0_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). You do **not** need a rooted TV.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.beb.plxnative_0.7.0_arm.ipk
```

[Installing and checking a download](https://github.com/GLinnik21/plx-native/blob/main/docs/install-and-verify.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. PlxNative is licensed GPL-3.0-or-later and bundles FFmpeg under LGPL-2.1-or-later; the complete corresponding source for both is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.7.0](https://github.com/GLinnik21/plx-native/blob/main/docs/release-audits/v0.7.0.md).
